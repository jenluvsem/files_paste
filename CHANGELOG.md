# Changelog

All notable changes to this project will be documented in this file.

## [1.0.1] - 2026-10-20

### Added
- Translations: Polish, German (informal and formal), French, Spanish
- Polish App Store summary

### Changed
- Compatibility widened to Nextcloud 32–35 (was 34 only); the full E2E suite passes on 32.0.15, 33.0.10, 34.0.5 and 35.0.2

## [1.0.0] - 2026-10-20

### Added
- Initial release
- Paste clipboard images directly into Files app
- Automatic filename generation with timestamp
- Collision handling to prevent overwriting files
- Support for PNG, JPEG, GIF, WebP formats
- Toast notifications for success and errors
- Works in All Files, Favorites, and Shared views
